# Prism MVP PRD v0.1

> 사주·서양 점성술·수비학을 하나의 사용자 경험으로 통합해, 전문 지식이 없는 사용자도 자신의 성향을 쉽게 이해하도록 돕는 한국어 자기이해 서비스 MVP.

- 문서 상태: Draft for Product Review
- 범위: MVP v0.1
- 개발 원칙: PRD 승인 전 구현하지 않음
- MVP 언어: 한국어
- MVP 인증 정책: 분석은 비로그인, 결과 저장 시 로그인 유도
- MVP 핵심 입력: 생년월일
- MVP 핵심 엔진: 사주 / 서양 점성술 / 수비학

---

## 1. 제품 개요

### 1.1 한 문장 정의

사용자가 생년월일을 입력하면 사주, 서양 점성술, 수비학의 기본 분석을 각각 계산하고, 세 체계가 공통으로 말하는 부분과 다르게 말하는 부분을 구조화해 누구나 이해하기 쉬운 언어로 보여주는 자기이해 서비스.

### 1.2 제품 비전

장기적으로는 사주·명리학, 서양 점성술, 수비학, 자미두수 등 서로 다른 전통적 해석 체계를 한곳에서 비교하고 교차 분석하는 종합 자기이해 플랫폼으로 확장한다.

MVP에서는 범위를 의도적으로 좁힌다. 첫 버전의 목표는 "기능의 수"가 아니라 아래 핵심 경험을 검증하는 것이다.

> 사용자가 생년월일 하나만 입력해도, 서로 다른 3개의 해석 체계가 자신을 어떻게 바라보는지 쉽고 흥미롭게 비교할 수 있다.

---

## 2. 문제 정의

현재 많은 사주·점성술 서비스는 다음 문제를 가진다.

1. 전문용어가 앞에 나와 초보 사용자가 이해하기 어렵다.
2. 결과가 정형화된 문장처럼 느껴져 개인화 체감이 낮다.
3. 서로 다른 체계를 사용하려면 여러 서비스를 각각 이용해야 한다.
4. 사주, 점성술, 수비학의 결과가 서로 어떻게 연결되는지 사용자가 직접 해석해야 한다.
5. 결과가 다르게 나왔을 때 무엇이 다른지 설명해주지 않는다.
6. LLM을 활용하더라도 계산 자체를 LLM에 맡기면 사실 관계가 흔들릴 위험이 있다.

---

## 3. 목표 사용자

### 3.1 장기 대상

연령, 성별, 국적에 제한을 두지 않는 일반 사용자.

### 3.2 MVP Primary Persona

사주나 별자리 등에 관심은 있지만 전문 지식은 없고, 복잡한 원국이나 천문 데이터보다 "그래서 나는 어떤 사람인가?"를 쉽고 재미있게 알고 싶은 한국어 사용자.

### 3.3 사용자 특성

- 사주·점성술을 전문적으로 공부한 사람일 필요가 없다.
- 결과를 재미 또는 자기이해 목적으로 소비한다.
- 긴 입력 폼보다 빠른 진입을 선호한다.
- 전문용어를 완전히 숨기기보다, 전문용어와 쉬운 설명을 함께 보는 것을 선호한다.
- 여러 분석이 일치하는 부분과 다른 부분에 흥미를 느낄 가능성이 높다.

---

## 4. 핵심 사용자 문제

### P1. 전문용어를 이해하기 어렵다

전문용어는 보존하되 반드시 쉬운 설명을 함께 제공한다.

예:

- 일간: "사주에서 나 자신을 대표하는 기준"
- 태양 별자리: "내가 기본적으로 자신을 표현하는 방식과 관련해 해석하는 요소"
- Life Path Number: "생년월일 숫자로 계산하는 수비학의 대표 지표"

### P2. 결과가 뻔하게 느껴진다

각 체계의 결과를 별도로 나열하는 데 그치지 않고, 공통점과 차이점을 교차 분석한다.

### P3. 사용자가 여러 사이트를 돌아다녀야 한다

하나의 입력으로 3개 엔진의 결과를 한 화면에서 확인하도록 한다.

### P4. 결과가 서로 다르면 해석하기 어렵다

일치·보완·상충·정보 부족 상태를 명시하고, 어느 체계를 임의로 정답으로 선택하지 않는다.

---

## 5. MVP 가치 제안

### 5.1 핵심 가치

"세 가지 관점으로 나를 보고, 겹치는 부분과 다른 부분을 한눈에 이해한다."

### 5.2 사용자에게 남겨야 할 감정

- "사주는 잘 몰라도 이해된다."
- "하나의 운세 결과보다 비교해서 보니 흥미롭다."
- "왜 이런 결과가 나왔는지 확인할 수 있다."
- "전문용어는 있지만 어렵게 느껴지지 않는다."

## 6. MVP 범위

### 6.1 포함

| 영역 | MVP 범위 |
|---|---|
| 언어 | 한국어 |
| 기본 입력 | 생년월일 |
| 성별 | 받지 않음 |
| 사주 | 출생시간 없이 계산 가능한 기본 명식 요소 |
| 서양 점성술 | 출생시간·지역 없이 계산 가능한 기본 요소 |
| 수비학 | 생년월일 기반 기본 수비학 |
| 결과 | 엔진별 원본 요약 + 쉬운 설명 |
| 교차 분석 | Agreement / Complementary / Divergence / Insufficient |
| 종합 결과 | 핵심 성향, 강점, 관계 스타일, 일하는 방식, 주의 성향 |
| 근거 보기 | 어떤 엔진의 어떤 데이터에서 나온 해석인지 표시 |
| Detailed Mode | 출생시간·출생지역 추가 입력을 통한 상세 분석의 최소 버전 |
| AI 대화 | Detailed Mode에서만 제공, 현재 계산 결과를 기반으로 제한된 질의 |
| 결과 저장 | 저장 시 로그인 유도, 구현 우선순위는 MVP 후반 |
| 반응형 | 모바일/데스크톱 웹 |

### 6.2 제외

MVP에서는 아래 기능을 구현하지 않는다.

- 자미두수
- Human Design
- 궁합
- 커플 분석
- 오늘의 운세
- 장기 세운/대운 리포트
- 결제
- 구독
- 전문가 상담
- 광고
- 푸시 알림
- 이메일 알림
- 커뮤니티
- 친구 기능
- 랭킹
- 공유 이미지 자동 생성
- 다국어
- 모바일 네이티브 앱
- 복잡한 관리자 페이지
- 추천 시스템
- 소셜 로그인
- 이름 기반 수비학

## 7. 제품 모드

### 7.1 Quick Reading

#### 목적

사용자가 생년월일만 입력하고 가장 빠르게 핵심 경험을 체험하도록 한다.

#### 입력

필수:
- 생년월일

받지 않음:
- 성별
- 이름
- 이메일
- 회원가입
- 출생시간
- 출생지역

#### 결과

1. 나를 설명하는 핵심 키워드
2. 핵심 성향
3. 강점
4. 관계 스타일
5. 일하는 방식
6. 주의할 성향
7. 세 엔진이 일치한 부분
8. 세 엔진이 다르게 보는 부분
9. 엔진별 기본 결과
10. "왜 이렇게 해석했나요?" 근거 보기
11. 상세 분석 CTA

#### UX 문구

> 출생시간 없이 확인할 수 있는 기본 분석입니다.  
> 더 정밀한 분석을 원하면 출생시간과 출생지역을 추가할 수 있습니다.

---

### 7.2 Detailed Reading

#### 목적

Quick Reading 사용자가 더 깊은 분석을 원할 때 추가 정보를 입력하도록 한다.

#### 추가 입력

- 출생시간
- 출생지역
- "출생시간을 모름" 선택 가능

#### 추가 기능

- 사주의 시주 등 시간 의존 요소
- 점성술의 출생시간/장소 의존 요소
- 보다 상세한 교차 분석
- 현재 분석 결과를 컨텍스트로 사용하는 AI 질문

#### AI 대화 범위

AI는 계산 결과를 해석하고 설명하는 역할만 한다.

예시 질문:
- 내 성향을 더 쉽게 설명해줘
- 연애에서는 어떤 특징이 있어?
- 일할 때 어떤 장점이 있어?
- 세 분석이 다르게 말하는 부분을 설명해줘
- 이 결과가 나온 근거를 알려줘

MVP에서는 무제한 인생상담 서비스로 확장하지 않는다.

## 8. 엔진별 계산 정책

### 8.1 공통 원칙

1. 결정 가능한 계산은 코드/검증된 라이브러리로 수행한다.
2. LLM이 원천 계산을 생성하지 않는다.
3. 입력 정보가 부족하면 추정하지 않는다.
4. 동일 입력은 동일 계산 결과를 반환해야 한다.
5. 계산 결과와 해석 결과를 분리한다.
6. 계산 규칙과 버전을 결과 데이터에 기록한다.

### 8.2 사주

Quick에서 사용:
- 년주
- 월주
- 일주
- 일간
- 기본 오행 분포
- 출생시간 없이 신뢰 가능한 기본 성향 해석 요소

Quick에서 사용하지 않음:
- 시주
- 정확한 출생시간을 전제로 하는 요소
- 상세 대운/세운
- 출생지 기반 진태양시 보정이 필요한 정밀 분석

### 8.3 서양 점성술

Quick에서 사용:
- 생년월일만으로 결정 가능한 기본 천체 위치 및 별자리 기반 요소

Quick에서 사용하지 않음:
- Ascendant
- House
- MC
- 출생시간·위치에 강하게 의존하는 요소
- 시간 정보가 없을 때 확정할 수 없는 정밀 Aspect

Detailed에서는 출생시간 + 출생지역이 있을 때 정밀 계산 범위를 확대한다.

### 8.4 수비학

Quick에서 사용:
- 생년월일 기반 핵심 숫자
- MVP에서 검증 가능한 최소 계산식

제외:
- 이름 기반 계산
- 언어별 이름 변환 규칙
- 복잡한 학파별 확장 해석

## 9. Normalized Interpretation Layer

서로 다른 엔진의 결과를 바로 LLM에 던지지 않는다.

각 엔진의 결과를 공통 데이터 구조로 변환한다.

```json
{
  "domain": "decision_style",
  "trait": "independence",
  "direction": "high",
  "source": "saju",
  "confidence": "supported",
  "evidence": [
    {
      "type": "day_master",
      "value": "..."
    }
  ]
}
```

MVP 공통 Domain 후보:
- self_expression
- decision_style
- social_style
- relationship_style
- work_style
- motivation
- emotional_style
- strengths
- caution_tendencies

목적:
- 엔진 간 비교 가능
- LLM 환각 감소
- 교차분석 테스트 가능
- 근거 추적 가능
- 향후 자미두수 등 신규 엔진 추가 용이

---

## 10. 교차 분석 정책

엔진 결과에는 우열을 두지 않는다.

### AGREEMENT
둘 이상의 엔진이 같은 방향의 특징을 지지한다.

### COMPLEMENTARY
서로 다른 관점이지만 동시에 성립 가능하다.

### DIVERGENCE
두 분석이 반대 방향을 제시한다.

출력 원칙:
- 숨기지 않는다.
- LLM이 하나를 임의 선택하지 않는다.
- 왜 다르게 볼 수 있는지 설명한다.

### INSUFFICIENT
필요한 입력이 없어 판단할 수 없다.

---

## 11. LLM 역할

### 허용
- 전문용어를 쉬운 한국어로 설명
- 구조화된 결과 요약
- 교차 분석 결과 자연어 변환
- 결과의 공통점/차이점 설명
- 사용자의 후속 질문에 현재 계산 결과 범위에서 답변

### 금지
- 사주 원국 직접 계산
- 행성 위치 직접 생성
- 수비학 숫자 임의 계산
- 없는 출생시간/장소 추정
- 엔진 간 충돌에서 임의 승자 결정
- 제공되지 않은 사실 생성
- 결정론적 미래 사건 단정

## 12. 정보 구조

### Landing
- 브랜드/서비스 이름
- 한 문장 가치 제안
- 생년월일 입력
- CTA: "나를 알아보기"
- 세 분석 체계 소개

### Loading
- 사주 계산 중
- 별자리 데이터 확인 중
- 수비학 계산 중
- 세 결과 비교 중
- 쉬운 설명 작성 중

실제 처리 단계와 거짓 없이 동기화한다.

### Quick Result
우선순위:
1. 핵심 키워드
2. 한 문장 종합 설명
3. 핵심 성향
4. 세 분석의 일치/차이
5. 엔진별 상세 카드
6. 근거 보기
7. 상세 분석 CTA
8. 저장 CTA

### Detailed Input
Quick 결과에서 자연스럽게 이동한다.

### Detailed Result
Quick 결과 구조를 유지하면서 시간/지역 기반 데이터를 추가한다.

### AI Question
Detailed 결과 내부에서 별도 섹션 또는 패널로 제공한다.

---

## 13. UX 원칙

### Progressive Disclosure
쉬운 설명 → 전문용어 → 근거 데이터 순으로 제공한다.

### 전문용어를 숨기지 않는다
모든 전문용어에는 쉬운 설명이 있어야 한다.

### 결과는 단정적으로 쓰지 않는다
결정론적 미래 예측 대신 "이 체계에서는 ~로 해석한다"는 표현을 사용한다.

### 데이터 부족은 명확하게 표현한다
출생시간이 없는 경우 제한되는 결과를 숨기지 않는다.

### 모바일 우선
첫 진입과 결과 소비는 모바일에서도 완결되어야 한다.

---

## 14. 디자인 방향

목표 감정:
- 신비롭지만 촌스럽지 않음
- 전문적이지만 어렵지 않음
- 콘텐츠가 많아도 답답하지 않음
- 운세 사이트보다 프리미엄 자기이해 제품에 가까움

피해야 할 스타일:
- 과도한 무속 이미지
- 금색/빨간색 과다 사용
- 한자와 별자리 장식의 과잉
- 카드가 지나치게 많은 대시보드
- 게임형 과한 애니메이션
- AI 서비스에서 흔한 그라디언트 남발

---

## 15. 로그인 및 저장 정책

비로그인:
- Quick Reading 가능
- Detailed Reading 가능
- 현재 세션 결과 확인 가능

저장 요청:
- "내 분석 저장하기"를 누르면 로그인/가입을 요청한다.

인증과 저장 기능은 핵심 분석 경험이 검증된 이후 구현할 수 있다.

## 21. MVP Acceptance Criteria

1. 로그인 없이 생년월일을 입력할 수 있다.
2. 유효하지 않은 날짜는 명확한 오류 메시지를 보여준다.
3. 사주 Quick 결과가 코드로 계산된다.
4. 서양 점성술 Quick 결과가 검증 가능한 엔진으로 계산된다.
5. 수비학 결과가 코드로 계산된다.
6. 세 엔진 결과가 공통 데이터 구조로 변환된다.
7. 교차 분석이 네 상태 중 하나로 분류된다.
8. 결과 화면에서 쉬운 설명을 먼저 볼 수 있다.
9. 전문용어와 해석 근거를 펼쳐볼 수 있다.
10. 출생시간이 없는 상태에서 시간 의존 데이터를 추정하지 않는다.
11. Detailed Mode에서 출생시간·출생지역을 추가할 수 있다.
12. Detailed Mode에서 현재 분석 기반 AI 질문을 할 수 있다.
13. LLM이 계산 결과를 변경하지 않는다.
14. 모바일과 데스크톱에서 핵심 흐름을 사용할 수 있다.
15. 핵심 계산 및 교차 분석 테스트가 통과한다.
16. 배포 환경에서 동일 핵심 흐름을 재검증한다.

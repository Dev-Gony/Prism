# Prism DaYun Calculation Spec

## 결정

Prism의 대운 계산은 임의 휴리스틱을 사용하지 않는다.

### 1. 순행 / 역행

전통적인 연간 음양 × 남/여 기준을 사용한다.

- 양년 + 남성 기준 → 순행
- 음년 + 여성 기준 → 순행
- 음년 + 남성 기준 → 역행
- 양년 + 여성 기준 → 역행

Prism은 사용자의 성정체성을 추정하지 않는다.
Detailed 입력에서 **대운 순역 계산 기준**을 별도 선택값으로 받는다.
미선택 시 대운은 계산하지 않는다.

### 2. 기산 방식

lunar-javascript / 6tail 계열의 `getYun(gender, 2)`와 동일한
minute-based sect 2 방식을 사용한다.

절기까지의 실제 분 차이:

- 4320분 = 1년
- 360분 = 1개월
- 12분 = 1일
- 잔여 1분 = 2시간

기산 결과는 년 / 월 / 일 / 시간 오프셋과 실제 기산 일시를 모두 저장한다.

### 3. 절기 방향

- 순행: 출생시각 → 다음 절(節)
- 역행: 이전 절(節) → 출생시각

절입 시각을 실제 시간 차이로 사용한다.

### 4. 시간대

현재 Prism의 한국 출생 계산 정책에 맞춰:

1. 입력은 KST(UTC+9)
2. lunar-javascript 절기 계산 civil-time 기준과 맞추기 위해 UTC+8 civil time으로 1시간 이동
3. 기산 결과는 다시 KST civil time으로 복원

이 규칙은 코드에 명시하고 숨겨진 보정으로 두지 않는다.

### 5. 출생시간 미상

출생시간 미상인 경우 정확한 절기까지의 시간 차이를 만들 수 없으므로
대운 기산을 임의 정오 등으로 대체하지 않는다.

결과:

- `daYun.available = false`
- pending reason 제공
- 다른 Detailed 분석은 정상 수행

### 6. 대운 주기

라이브러리의 DaYun period를 사용한다.

각 주기에 저장:

- 간지
- 천간 십신
- 지지 본기 십신
- 시작 / 종료 연도
- 시작 / 종료 나이
- 실제 시작 일시
- 다음 대운 시작 일시(exclusive)
- 旬
- 旬空
- 원국 지지와 합 / 충 / 형 / 파 / 해

index 0의 기산 전 구간은 실제 대운 목록에서 제외하고,
index 1부터 10개 대운을 사용한다.

### 7. 나이 기준

lunar-javascript DaYun 구현과 동일하게 연도 차이에 +1을 사용하는
세는나이(연도 기준)를 표시한다.

### 8. Destiny Timing 연동

선택 날짜가 대운의 실제 startDateTime 이상,
다음 대운 startDateTime 미만이면 해당 대운을 활성 대운으로 판정한다.

활성 대운은:

- 대운 천간 십신
- 원국과 대운 지지 관계
- 세운
- 월운

과 함께 Saju timing signal에 들어간다.

## 하지 않는 것

- 출생시간을 임의 생성하지 않음
- 남/여 기준값을 계정 정보나 이름에서 추정하지 않음
- 대운 시작 나이를 임의 반올림 공식으로 재구현하지 않음
- 대운을 단일 사건 예언으로 변환하지 않음
- 진태양시 보정은 현재 미적용이며 UI warning에 명시

## Reference

Prism은 6tail lunar 계열의 공개된 Yun / DaYun 구현과 테스트 케이스를 기준으로
대운 계산 규칙을 고정한다.

향후 테스트 단계에서 upstream Yun reference cases와 Prism 결과를
golden test로 고정한다.
